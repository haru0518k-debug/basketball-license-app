# バスケ ライセンス学習（PWA 試作版）

バスケットボールの **審判** と **コーチ** のライセンス取得に向けた学習アプリです。
ビルド不要の HTML/JS で作られており、スマホのホーム画面に追加するとアプリのように使えます。

## 機能
- 審判／コーチの切り替え
- 分野別の理解度（正答率・習得数）を棒グラフで表示
- **苦手分析**：正答率80%未満の分野を「苦手」として表示
- **苦手克服10問**：間違えた問題・苦手分野・未解答・しばらく解いていない問題を優先して出題
- 間違えた問題だけの復習、分野別・ランダム出題
- 直近14日の学習量グラフ
- 学習記録は端末内（localStorage）に保存。サーバー不要

## ファイル構成
| ファイル | 役割 |
|---|---|
| `index.html` | 画面の土台 |
| `app.js` | 画面・出題・進捗/苦手分析のロジック |
| `questions.js` | 問題データ（ここに問題を追加） |
| `style.css` | デザイン（ライト/ダーク対応） |
| `manifest.webmanifest`, `sw.js`, `icon.svg` | ホーム画面追加・オフライン対応 |

## 問題の追加
`questions.js` の `QUESTIONS` に次の形式で追加します。`category` は `CATEGORIES` にある名前を使います。

```js
{ id: "r22", track: "referee", category: "ファウル",
  q: "問題文", choices: ["A", "B", "C", "D"], answer: 1, exp: "解説" },
```

## スマホで使うには
iPhone/Android でホーム画面に追加するには HTTPS で公開する必要があります。
GitHub Pages や Netlify などにこのフォルダをそのままアップロードすれば公開できます。
問題やファイルを更新したら `sw.js` の `CACHE` のバージョンを上げてください。

## 注意
収録問題はオリジナルの練習問題で、公式の試験問題ではありません。
